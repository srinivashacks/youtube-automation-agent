# ShortsPilot Prompt Library

These prompts are starting templates. Users should verify outputs before publishing.

## Research and topic prompts

1. Give me 10 evergreen Shorts topics for [NICHE] aimed at [AUDIENCE].
2. Turn this broad subject into 10 specific 45-second video ideas: [SUBJECT].
3. Find the clearest beginner question someone might ask about [TOPIC].
4. Rank these topics by usefulness for a beginner audience: [TOPICS].
5. Turn this common misconception into a fact-checking Short: [CLAIM].
6. Give me three angles on [TOPIC]: beginner, practical, surprising.
7. Create a five-day Shorts topic sequence teaching [SKILL] from zero.
8. Suggest a follow-up Short that naturally continues this topic: [TOPIC].
9. Identify claims in this draft that require verification: [DRAFT].
10. Rewrite this topic so it does not depend on copyrighted clips: [TOPIC].

## Hook prompts

11. Write five honest hooks for [TOPIC] without clickbait.
12. Give me three curiosity hooks under 12 words for [TOPIC].
13. Write a hook that states the viewer's problem clearly: [PROBLEM].
14. Write a hook for a beginner who thinks [MISCONCEPTION].
15. Turn this title into a stronger spoken opening: [TITLE].

## Script prompts

16. Write a 45-second script about [TOPIC] for [AUDIENCE].
17. Explain [CONCEPT] using one simple analogy and one example.
18. Convert these notes into a concise spoken script: [NOTES].
19. Remove filler and repetition from this script: [SCRIPT].
20. Rewrite this script in simple Indian English: [SCRIPT].
21. Make this explanation understandable to a 15-year-old without losing accuracy.
22. Give the script a clear hook, explanation and final takeaway.
23. Reduce this script to approximately 110 spoken words.
24. Identify unsupported claims in this script and mark them.
25. Rewrite the script so every sentence adds information.

## Visual prompts

26. Create five visual scene ideas for this script: [SCRIPT].
27. Describe a clean vertical illustration for this scene: [SCENE].
28. Give me a consistent visual style for a ten-video series about [NICHE].
29. Convert this concept into a simple infographic scene: [CONCEPT].
30. Suggest visuals that can be generated without using copyrighted characters.

## SEO and packaging prompts

31. Generate five accurate Shorts titles for [TOPIC].
32. Write a two-sentence description without exaggerated claims.
33. Suggest 10 relevant search phrases for [TOPIC].
34. Give me three thumbnail text options under five words.
35. Rewrite this title to be specific rather than sensational: [TITLE].
36. Suggest a series name for these five related videos: [TOPICS].
37. Create a concise pinned-comment question that encourages useful discussion.
38. Generate tags based only on the actual subject, not unrelated trending terms.

## Quality-control prompts

39. Fact-check this script conceptually and list claims that need external verification: [SCRIPT].
40. Find logical contradictions in this draft: [DRAFT].
41. Identify any financial, medical or legal advice in this script that should be removed or qualified.
42. Identify statements that sound like guaranteed outcomes.
43. Identify potentially copyrighted material or celebrity imitation in this content.
44. Rewrite unsupported statistics as qualitative statements.
45. Check whether the title accurately represents the script.
46. List five questions a skeptical viewer could ask about this claim.
47. Identify sentences that may mislead a beginner.
48. Create a final publishing checklist from this draft.
49. Give me a one-sentence factual takeaway from this video.
50. Score this draft from 1–10 for clarity, usefulness and accuracy, and explain the lowest score.
