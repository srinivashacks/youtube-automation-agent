# ShortsPilot Pre-Launch Checklist

## Product readiness

- [ ] Fresh install works on Node 18+
- [ ] Guided walkthrough works
- [ ] At least one supported AI provider works using its current free/paid terms
- [ ] YouTube OAuth/publishing flow has been tested safely
- [ ] Generated output can be reviewed before publishing
- [ ] Common setup errors documented
- [ ] Sample configuration contains no secrets
- [ ] Upstream LICENSE and attribution remain intact
- [ ] Third-party dependency/provider terms reviewed

## Customer package

- [ ] Customer README
- [ ] Setup guide
- [ ] Preflight checker
- [ ] 10 niche starter packs
- [ ] 50+ reusable prompts
- [ ] Demo/sample workflow
- [ ] Troubleshooting guide
- [ ] Release ZIP
- [ ] Screenshots
- [ ] Short demo video or GIF

## Sales validation

- [ ] Gumroad creator account ready
- [ ] Product page drafted
- [ ] Launch price tested at ₹499
- [ ] Optional setup service tested separately
- [ ] 10 relevant prospects identified
- [ ] Outreach message tested with a small batch
- [ ] Buyer objections recorded

## Do not claim

- Guaranteed views
- Guaranteed subscribers
- Guaranteed monetization
- Guaranteed income
- Fully autonomous success without review

## Validation rule

Do not spend weeks adding features before testing demand. Once the package is usable, publish a small launch offer and use real buyer objections to decide what to improve next.
