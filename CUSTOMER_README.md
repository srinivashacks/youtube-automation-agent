# ShortsPilot — AI Shorts Production Kit

## What this is

ShortsPilot is a beginner-oriented packaging of an open-source AI-assisted YouTube automation project. It is designed to make the technical setup easier to understand and repeat.

**It does not guarantee YouTube views, subscribers, monetization, revenue, or passive income.**

## What you get

- Guided setup path
- Preflight checks
- Reusable niche and topic ideas
- Prompt templates for scripts and metadata
- Sample configuration
- Troubleshooting guidance
- A repeatable workflow from idea → script → media → render → publish

## Before you start

You need:

- Node.js 18 or newer
- A Google account and YouTube channel if you want publishing
- At least one supported AI provider configured according to its current terms
- Enough local disk space for generated media

Start with the guided walkthrough in the main project documentation. Do not publish generated videos publicly until you have reviewed them yourself.

## Responsible use

Review every generated script, image, voice track, title, description, and thumbnail before publishing. You are responsible for complying with YouTube rules, copyright requirements, disclosure requirements, and the terms of any AI/API provider you use.
